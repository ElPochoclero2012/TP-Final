# 🎮 SteamLite

Sistema de gestión y distribución digital de videojuegos desarrollado en lenguaje C para consola utilizando CodeBlocks.

---

# 📌 Descripción

SteamLite es un proyecto académico desarrollado para la materia Programación I, cuyo objetivo es simular el funcionamiento básico de una plataforma digital de videojuegos inspirada en sistemas como Steam.

El proyecto busca aplicar conceptos fundamentales de programación en C mediante el desarrollo de un sistema modular y escalable en consola.

El sistema permitirá administrar:
- videojuegos,
- usuarios,
- bibliotecas digitales,
- compras,
- estadísticas,
- y persistencia de datos mediante archivos binarios.

---

# 🛠️ Tecnologías utilizadas

- Lenguaje C
- CodeBlocks
- Git & GitHub
- Consola ANSI
- Archivos binarios (`.dat`)
